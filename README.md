#InAmigos Foundation - NGO Website Feature Highlight

A UI/UX concept designed in Figma for an NGO website.

## Key Features

- Donation section
- Volunteer registration
- Impact showcase
- Campaigns
- Community testimonials
- Clear calls-to-action

## Tools Used

- Figma
- UI/UX Design

## Project Goal

To explore website features that can make an NGO website clear,
engaging, and easier for visitors to support the organization's work.
